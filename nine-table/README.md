# 🚴🏻‍♀️ مغامرات بطلة جدول التسعة

لعبة تعليمية ثلاثية الأبعاد (React + Three.js) لتعلّم جدول ضرب ٩ فقط (من ٩ × ١ إلى ٩ × ١٠) للبنات في المرحلة الابتدائية.

- ثلاث بطلات للاختيار (لمى، ريم، جنى) بدراجات تتحرك عجلاتها ودوّاساتها فعليًا.
- المرحلة ١ «طريق النجوم الوردية»: ثلاثة مسارات تحمل الإجابات، وجّهي الدراجة للإجابة الصحيحة.
- المرحلة ٢ «محطات أميرات الضرب»: خمس بوابات سحرية، فرصة ثانية مع تلميح بالمجموعات.
- المرحلة ٣ «منعطفات البطلات»: جسور ونجوم وكعكات لطيفة، بوابات عكسية (أيّ بوابة ناتجها ٥٤؟)، ثم «تحدي العبقريات» في القصر الذهبي.
- منصة تتويج وشهادة «بطلة جدول التسعة الذهبية» قابلة للتنزيل والمشاركة.
- قراءة صوتية عربية للأسئلة، تكرار ذكي للعمليات الخاطئة، ثلاث درجات صعوبة، حفظ التقدم على الجهاز.

## النشر (رابط عام يفتح من واتساب بلا تسجيل)

الملف الجاهز للنشر: `dist/index.html` (ملف واحد يحتوي كل شيء).

**أسهل طريقة – Netlify Drop:**
1. افتحي https://app.netlify.com/drop وأنشئي حسابًا مجانيًا (للمعلمة فقط، الطالبات لا يحتجن حسابًا).
2. اسحبي مجلد `dist` إلى الصفحة.
3. ستحصلين على رابط مثل `https://xxxx.netlify.app` — يمكن تغيير الاسم من Site settings → Change site name.

**Vercel / Netlify من GitHub:** اختاري المجلد `nine-table` كجذر للمشروع؛ الإعدادات موجودة في `netlify.toml` و`vercel.json` (الأمر `npm run build` والمخرجات `dist`).

## التطوير

```bash
npm install
npm run dev     # تشغيل محلي
npm run build   # إنتاج dist/index.html
```

تحكم: الأسهم ← → أو A / D، P للإيقاف المؤقت، R لإعادة السؤال، 1/2/3 للإجابة في المحطات. على الجوال: أزرار كبيرة أو السحب أو لمس الإجابة.
